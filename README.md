# MrKatooni Store Theme

A WordPress block theme built for the [MrKatooni WooCommerce store](https://mrkatoonisari.com/) in Sari. The theme includes editable storefront layouts and WooCommerce templates for product browsing and search.

[Read the Persian MrKatooni case study](https://littlejay.tech/fa/projects/mrkatooni) for screenshots and a description of the theme and layout work.

## Requirements

- WordPress 6.7 or newer
- PHP 8.0 or newer
- WooCommerce for the storefront

## Installation

Copy the theme directory to `wp-content/themes/mrkatooni-store-theme`, then activate **MrKatooni Store** under **Appearance → Themes**. Use **Appearance → Editor** to edit block templates and template parts.

The theme metadata declares GPL v2 or later.
